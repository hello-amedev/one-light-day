# ボイジャー本体の 3D モデル

取得日: 2026-11-21。「ボイジャー本体」の視点(`src/stage/craft.ts`)で、機体を回して見るためのモデル。

## 出どころ

| 項目 | 内容 |
|---|---|
| 配布ページ | https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Voyager%20Probe%20(B) (NASA 3D Resources) |
| 元のファイル名 | `Voyager Probe (B).glb` |
| 取得した先 | https://raw.githubusercontent.com/nasa/NASA-3D-Resources/master/3D%20Models/Voyager%20Probe%20(B)/Voyager%20Probe%20(B).glb |
| 同梱したファイル | `public/models/voyager.glb`(1,720,864 バイト。Git LFS のポインタではなく、先頭が `glTF` の実体) |
| 中身 | メッシュは Draco 圧縮、表面の画像は WebP(PNG の控えつき)。3 つの部品(本体 `tex_01`、皿 `tex_02_AO`、母体 `tex_02_AO_dark`) |
| 使わなかったもの | 「Voyager Probe (A)」: 実物に無い脚が付いている |

## 条件

- NASA 3D Resources の素材: 無料で使える・著作権なし。出典を書く
- NASA が推薦・承認しているように見せない。NASA / JPL のロゴは使わない(モデルにロゴは無い)
- 出典の文: 「ボイジャー1号の 3D モデル: NASA 3D Resources」

## 大きさ・向きの決め方

glb の JSON(accessor の min / max、ノードの縮め)と、読み込んだ後の各メッシュの外形から調べた。モデルの 1 単位はほぼ 1 m。

- 皿(`tex_02_AO`): 幅 3.81、深さ 1.6(y 0.7〜2.31)。実際の高利得アンテナの直径 3.7 m に合わせるため、モデルの 1 単位 = 3.7 / 3.81 m(約 0.971 m)に縮める。km にすると 1 単位 = 約 9.7e-4 km
- 皿の軸: +y(凹んだ側が +y)。+y から見ると、皿の内側と、中央へ延びる 3 本の支えが見える
- 磁力計のブーム: +z の向き(長さ約 12.7)。皿の軸のまわりの回転は、このブームが画面の上(黄道の北)を向くよう一定にする
- 機体の外形全体: x ±3.9(プラズマ波のアンテナ)、y −2.0〜(皿より前に出るものは無い)、z −4.2〜12.7
- 回る中心: 皿と母体のあたり(モデルの座標で (0, 1.5, 0))

## 描き方

- 色の扱いは本体のほかの 3D と同じ(色の変換なし)。光は太陽の方向からの平行光と、影の側が真っ黒にならないための弱い補助光
- 3D の圧縮の復号の部品は `public/draco/`(three.js 同梱。Apache-2.0)。外部には読みに行かない
- 読み込みは、本体の視点を最初に開いた時だけ。最初に読む JS には含めない
