# 再現と演出の区別(出典のページに書く内容の元)

サイトの中で、実際のデータで再現している所と、見せ方として作っている所の一覧。第5段階で出典のページにまとめる。

## 再現している

- ボイジャー1号・惑星・月・衛星の位置(NASA JPL Horizons のデータ。地球からの距離の差は最大 15km ほど)
- 星の位置・明るさの順・色(HYG データベース)と、天の川の位置(NASA の全天の画像)
- 天体の大きさ、自転軸の向きと自転の角度(国際天文学連合の回転要素)、木星と土星の扁平
- 昼と夜の向き(太陽の方向)
- 土星の環の半径の区分と間隙、環に落ちる土星の影、土星に落ちる環の影の位置
- 土星の環の明るさの並び: 太陽が当たる側から見ると濃い B 環が最も明るく、裏側から見ると B 環は暗く、薄い C 環・カッシーニの間隙・A 環のほうが明るい
  (環の粒が光を 1 回散らす計算。ボイジャー1号が裏側から撮った写真と同じ並びになる)
- 地球・月・木星・イオの表面(NASA・USGS の画像)。ペイル・ブルー・ドットの写真(NASA/JPL-Caltech の 2020 年の再処理版)

## 見せ方として作っている(演出)

- **視界の向き**: 自由に見回せる。当時カメラが実際に向いていた方向ではない
- **星と天体の明るさ**: 太陽が視界にあっても星と天の川が見える。遠い惑星の点は、実際より明るく描く
- **太陽の光**: にじみと十字の光条は見せ方で、実際のカメラの写り方ではない
- **地球**: 雲は 2001 年の観測の合成で、1977 年の打ち上げの日の雲ではない。縁の大気の青い光と、夜の側のごく薄い明るさは演出。街の灯りは描いていない
- **木星**: 表面は 2000 年にカッシーニが撮った姿で、1979 年の姿ではない。経度の基準が仮なので、大赤斑の位置は実際と合わない
- **エウロパ・ガニメデ・カリスト**: 元の地図は白黒で、それぞれの平均的な色を乗せている
- **土星**: 縞の色とむら、環の細かな濃淡と色は、プログラムで描いたもの(公表されている寸法をもとにした絵)
- **タイタン**: 橙色のもやは、画像を使わずに描いたもの
- **太陽圏の境**: 形は分かっていないので描いていない
- **衛星**: 木星・土星の通過の前後 3 日だけ描く。それ以外の時期と、そのほかの衛星は描いていない
