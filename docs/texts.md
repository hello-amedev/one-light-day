# 画面に出る文言の一覧

> 公開の前に、画面の文言を確認するための一覧。`src/lib/i18n/ja/` の辞書から `node scripts/dump-texts.mjs` で作っている。
> 直す時は、この表ではなく辞書を直してから作り直す（`node scripts/dump-texts.mjs`。辞書と食い違っていないかは `--check` で調べられる）。
> 値の入る文は、例の値を入れた形で載せている。

## 共通

どの画面でも同じ意味になる文言

| キー | 文言 | どこに出るか |
|---|---|---|
| common.title | VOYAGER 1 | 画面の左上の題字 |
| common.listSeparator | 、 | 名前を並べる時の区切り（「木星、土星」のように） |
| common.loading | 位置のデータを読み込んでいます | 位置のデータを読み込んでいる間の中央の表示 |
| common.loadFailed | データを読み込めませんでした。ページを読み込み直してください。 | 位置のデータを読み込めなかった時の中央の表示 |

## 開いた直後の題字と案内

題字と副題はサイト名の仮称。差し替える時は src/lib/i18n/ja/intro.ts だけを直す

| キー | 文言 | どこに出るか |
|---|---|---|
| intro.title | ONE LIGHT-DAY | 開いた直後の中央の題字 |
| intro.subtitle | ボイジャー1号、1光日の旅 | 開いた直後の題字の下の副題 |
| intro.guide | 下の時間軸で、好きな日へ移れます | 自動再生が今日で止まった後、画面の中央より少し下に出る案内 |

#### 2 節　操作のしかた

| 種類 | 文言 |
|---|---|
| 見出し | 操作のしかた |
| 項目 | 時間軸　画面下の軸のつまみをドラッグすると、打ち上げから今日までの好きな日へ移れます。金の刻みは名場面です。 |
| 項目 | 送りダイヤル　「1日」「1時間」の左右の矢印で、時刻を戻し、進めます。 |

| 項目 | 向くボタン　「地球を向く」のように、見る向きをその天体へ合わせます。木星・土星・月のボタンは、近い時期だけ出ます。 |
| 項目 | 視点の切り替え　「ボイジャーの視界」は探査機から見た眺め、「引きの眺め」は太陽系を外から見渡す眺めです。 |
