# 画面に出る文言の一覧

> 公開の前に、画面の文言を確認するための一覧。`src/lib/i18n/ja/` の辞書から `node scripts/dump-texts.mjs` で作っている。
> 直す時は、この表ではなく辞書を直してから作り直す（`node scripts/dump-texts.mjs`。辞書と食い違っていないかは `--check` で調べられる）。
> 値の入る文は、例の値を入れた形で載せている。

## 共通

どの画面でも同じ意味になる文言

| キー | 文言 | どこに出るか |
|---|---|---|
| common.title | VOYAGER 1 | 画面の左上の題字 |
| common.listSeparator | 、 | 名前を並べる時の区切り（「木星、土星」のように） |
| common.restart | 最初から再生 | 左上の題字（押すと開いた直後の状態に戻り、打ち上げから自動再生し直す）の指した時の名前 |
| common.phraseBreaks | 。、  | 名場面・出来事の文で、改行してよい所の記号（この記号の直後でだけ改行する。画面には出ない） |
| common.loading | ボイジャー1号と天体の位置を読み込んでいます | 位置のデータを読み込んでいる間の中央の表示 |
| common.loadFailed | データを読み込めませんでした。ページを再読み込みしてください。 | 位置のデータを読み込めなかった時の中央の表示 |

## 開いた直後の題字と案内

題字と副題はサイト名の仮称。差し替える時は src/lib/i18n/ja/intro.ts だけを直す

| キー | 文言 | どこに出るか |
|---|---|---|
| intro.title | ONE LIGHT-DAY | 開いた直後の中央の題字(1 行目) |
| intro.days | 17,971 EARTH DAYS | 開いた直後の題字の 2 行目(打ち上げから、地球から 1 光日に達した日までの日数) |
| intro.subtitle | ボイジャー1号、1光日に至る旅 | 開いた直後の題字の下の副題 |
| intro.guide | 下の時系列で移動できます | 自動再生が今日で止まった後、画面の中央より少し下に出る案内 |
