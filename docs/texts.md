# 画面に出る文言の一覧

> 公開の前に、画面の文言を確認するための一覧。`src/lib/i18n/ja/` の辞書から `node scripts/dump-texts.mjs` で作っている。
> 直す時は、この表ではなく辞書を直してから作り直す（`node scripts/dump-texts.mjs`。辞書と食い違っていないかは `--check` で調べられる）。
> 値の入る文は、例の値を入れた形で載せている。

## 共通

どの画面でも同じ意味になる文言

| キー | 文言 | どこに出るか |
|---|---|---|
| common.title | VOYAGER 1 | 画面の左上の題字 |
| common.listSeparator | 、 | 名前を並べる時の区切り（「木星、土星」のように） |
| common.loading | 位置のデータを読み込んでいます | 位置のデータを読み込んでいる間の中央の表示 |
| common.loadFailed | データを読み込めませんでした。ページを読み込み直してください。 | 位置のデータを読み込めなかった時の中央の表示 |

## 開いた直後の題字と案内

| キー | 文言 | どこに出るか |
|---|---|---|
| intro.title | ONE LIGHT-DAY | 開いた直後の中央の題字(1 行目) |
| intro.days | 17,971 EARTH DAYS | 開いた直後の題字の 2 行目(打ち上げから、地球から 1 光日に達した日までの日数) |

| 項目 | 再生と送り　再生のボタンで時間が進みます。隣の速さのボタン（最初は「1秒＝1日」）を押すたびに、1秒で進む時間が1時間・1日・1か月・1年の順に切り替わります。左右の矢印では、1日ずつ（速さが1時間の時は1時間ずつ）戻したり進めたりできます。 |

| 項目 | 向く　左下のボタンで天体を選ぶと、その天体が画面の中央に来るように向きが変わります。地球、太陽、進む先（ボイジャー1号が進んでいく方向）はいつでも選べます。木星、土星、月、衛星は、ボイジャー1号の近くにある時期だけ選べます。 |
| 項目 | 視点の切り替え　左上の3つのボタンで眺めを切り替えます。「ボイジャーの視界」はボイジャー1号の位置から見た眺め、「引きの眺め」は太陽系を外から見渡す眺め、「ボイジャー本体」は機体をそばから見る眺めです。 |
| 項目 | 見回しと拡大　画面をドラッグすると見回せます。ボイジャーの視界では、ホイールか2本指のつまみで約143倍まで拡大でき、右下に倍率が出ます。いちばん拡大した時の視野は、ボイジャー1号の狭角カメラ（望遠のカメラ）と同じ約0.4度です。 |
| 項目 | メニュー　右上のボタンで、天体の名前と目印、惑星の軌道、名場面と出来事の文を、表示するかどうか切り替えられます。「星空だけを表示」を選ぶと数字と操作が隠れ、画面を押すと戻ります。 |
